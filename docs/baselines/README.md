# Baselines

Status: historical snapshots only. Commands, modules, tests, and capabilities recorded here apply to the named commit and are not current execution instructions.

This directory stores structural baseline records used for regression protection.

Baseline documents summarize behavior that was verified at a historical commit. Current implementation truth comes from the tracked code, current tests, and `contracts/CURRENT_ARTIFACT_CONTRACTS.md`.

Generated runtime artifacts stay under ignored `runs/<run_id>/` directories and must not be committed.
