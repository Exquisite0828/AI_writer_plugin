# Functional Safety Requirement Writing Reference

This reference describes general writing quality for functional safety requirements.
It is not project evidence.

Useful requirement wording is specific, testable, traceable, and avoids ambiguous verbs.
A functional safety requirement is normally linked to a safety goal and a verification approach.
General methodology references may help reviewers check wording quality, but they cannot prove project-specific safety goals, ASIL inheritance, verification status, or final acceptance.

This reference must not be cited as fact support for this project's FSR content.
