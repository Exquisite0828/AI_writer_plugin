# SWE.2 Demo Review Checklist

Review criteria only. Do not use as factual evidence.

- [ ] Static software architecture defined (components, interfaces)
- [ ] Dynamic aspects addressed (tasks, scheduling, modes)
- [ ] Bidirectional traceability to SwRS
- [ ] Consistency between SwRS and software architecture
- [ ] Resource and timing constraints documented or open
- [ ] No detailed design or code leakage
- [ ] No professional approval or compliance claims
