# ASPICE SWE.2 and ISO 26262-6 Interface Reference

Methodology reference only. Do not use as project-specific EPS facts.

## ASPICE SWE.2 (orientation)

- Specify static aspects of software architectural design
- Specify dynamic aspects of software architectural design
- Establish bidirectional traceability to software requirements
- Ensure consistency between SwRS and software architecture

## ISO 26262-6 §7 (orientation)

Software architectural design shall be derived from software requirements and provide input to detailed design. Safety-related constraints shall be traced from upstream safety inputs without re-performing hazard analysis in the SwAD.
