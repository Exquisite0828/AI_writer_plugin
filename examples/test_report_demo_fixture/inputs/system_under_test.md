# Markdown Export Service Test Object

## System Under Test

The system under test is the Markdown Export Service version 0.9.3 for the AI writing plugin demo environment.

## Test Target

The test target is deterministic export of generated Markdown report artifacts from a completed writing run.

## Included Scope

- Markdown final report generation.
- Delivery summary generation.
- Source citation preservation in generated report text.
- Error handling for missing required source inputs.

## Scope Limits

- PDF and DOCX rendering are outside this test pass.
- Browser-based visual inspection is outside this test pass.
- Release readiness is not confirmed by this material.
