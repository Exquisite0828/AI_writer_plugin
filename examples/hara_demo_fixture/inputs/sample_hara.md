# HARA Demo Sample Shape

This sample is for structure, style, and table shape only.

It is not factual evidence for the EPS demo item.

Do not use this sample to support hazards, hazardous events, S/E/C ratings, ASIL, safety goals, or final conclusions.

## Example Table Shape

| Function | Malfunction candidate | Operational situation candidate | Evidence note | Confirmation status |
|---|---|---|---|---|
| Example function | Example malfunction | Example situation | Source support required | NEEDS_USER_CONFIRMATION |

## Example Conservative Wording

Candidate hazards and hazardous events should be written as candidates when professional judgment has not been confirmed.

Rating placeholders should remain `S? / E? / C?`.

ASIL wording should remain `ASIL candidate remains TBD` until qualified human confirmation is available.
