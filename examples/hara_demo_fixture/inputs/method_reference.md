# HARA Demo Method Reference

## Method Context

HARA analysis identifies hazards, hazardous events, and risk classifications for safety-related vehicle functions.

Severity, exposure, and controllability are professional judgments.

ASIL classification depends on confirmed severity, exposure, and controllability.

Safety goals are derived from confirmed hazardous events and confirmed risk classification.

## Use Constraint

This method reference can support methodology wording and review criteria.

It is not project-specific EPS evidence.

It does not confirm any hazard, hazardous event, severity rating, exposure rating, controllability rating, ASIL, safety goal, or acceptance conclusion for the demo item.
