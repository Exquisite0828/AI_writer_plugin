# EPS Steering Assist Demo Item

## System Boundary

The demo item includes the steering torque sensor, electric power steering ECU, assist motor, and vehicle speed input.

## Steering Assist Function

The EPS steering assist function provides steering torque assistance based on driver steering input and vehicle speed.

## Operational Context

The function is intended for normal passenger vehicle driving where the driver remains responsible for steering.

## Known Limitation

Braking and throttle control are out of scope for this demo item.
