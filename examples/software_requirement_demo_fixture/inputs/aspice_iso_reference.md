# ASPICE SWE.1 and ISO 26262-6 Interface Reference

Methodology reference only. Do not use as project-specific EPS facts.

## ASPICE SWE.1 (orientation)

- Analyze software requirements from system requirements
- Specify structured software requirements
- Establish bidirectional traceability
- Ensure consistency with system requirements and architecture context

## ISO 26262-6 (orientation)

Software requirements shall be derived from system development inputs. Safety-related software requirements shall trace from upstream safety inputs without re-performing hazard analysis in SwRS.
