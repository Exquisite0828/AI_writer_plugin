# 技术方案评审清单

- 文档应覆盖模板要求的章节。
- 架构决策必须由项目 source 材料支持，或标记为 NEEDS_USER_CONFIRMATION。
- 性能目标必须由项目 source 材料支持，或标记为 NEEDS_USER_CONFIRMATION。
- 安全边界必须由项目 source 材料支持，或标记为 NEEDS_USER_CONFIRMATION。
- 成本估算必须由项目 source 材料支持，或标记为 NEEDS_USER_CONFIRMATION。
- 上线风险和回滚方案必须被说明。
- sample 文档不能作为事实来源。
- reference 材料不能证明项目特定事实。
- final status 不能在没有 HITL 的情况下声称专业批准。
