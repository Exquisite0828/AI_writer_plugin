# 需求说明

## 目标

- 支持后端服务按阶段启用或关闭功能。
- 保持当前 REST API 的读取兼容性。
- 记录功能开关创建、修改、启用、禁用等审计事件。
- 支持服务团队逐步迁移到新的配置管理方式。

## 非目标

- 本项目不替换所有客户端侧配置机制。
- 本项目不在当前阶段给出最终成本估算。
- 本项目不直接批准最终架构方案。
- 本项目不承诺生产上线已获批准。

## 已确认需求

- 现有后端客户端必须继续通过当前 API contract 读取开关状态。
- 功能开关变更事件必须记录到审计日志。
- 上线计划必须包含回滚步骤。
- 第一阶段只覆盖内部后端服务，不覆盖移动端客户端。

## 待确认需求

- 性能目标需要服务负责人确认。
- 安全边界需要安全负责人和架构评审确认。
- 上线风险接受需要项目负责人确认。
- 成本估算需要基础设施团队补充容量数据。
