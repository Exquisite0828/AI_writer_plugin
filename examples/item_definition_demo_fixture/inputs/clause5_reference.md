# ISO 26262-3 Clause 5 Method Reference (Demo)

Methodology reference only — not project-specific EPS facts.

## Clause 5 — Item Definition (summary for writing guidance)

Item definition shall describe, as applicable:

1. **Item identification** — name, version, variant (§5.4.1).
2. **Functions** — what the item does (§5.4.2).
3. **System boundary** — what is inside and outside the item (§5.4.3).
4. **External interfaces** — interactions with environment and other elements (§5.4.3).
5. **Operating conditions** — environmental and operational constraints (§5.4.4).
6. **Assumptions and dependencies** (§5.4.4).
7. **Reasonably foreseeable misuse** (§5.4.4 b).

## Relationship to HARA

Item definition is an input to hazard analysis and risk assessment (Clause 6). Item definition does **not** replace HARA and does not include hazard ratings or safety goals.

## Writing discipline (demo reference)

- Trace claims to project source documents.
- Mark gaps explicitly; do not silently infer missing boundaries or interfaces.
- Interface tables shall include signal direction (input / output / bidirectional).
