# Custom Technical Note Template

## Background

Summarize why the note is needed and what confirmed source material is available.

## Scope

State the system scope, environment scope, and explicit out-of-scope items.

## Technical Notes

Describe the implementation facts supported by source material.

## Compatibility and Constraints

List compatibility coverage, constraints, and unsupported compatibility claims.

## Deployment Risks and Open Questions

Carry unresolved deployment risks and source gaps forward.

## Human Confirmations

List every critical claim that requires human confirmation before final use.
